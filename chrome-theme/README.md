# Matte AMOLED Black Chrome Theme

A true matte AMOLED pitch-black theme for Google Chrome that seamlessly matches the **Monochrome New Tab** page.

## What It Styles
- **Omnibox (Address Bar)**: True matte black (`#000000`) with high-contrast crisp white typography.
- **Tabs**: Pitch-black active and background tabs with white text (`#FFFFFF`) and subtle inactive text (`#B4B4B4`).
- **Toolbar & Frame**: Pure black (`#000000`) browser frame and navigation row with zero gray borders or colored accents.

---

## How to Install (Takes 10 Seconds)

### Method 1: Load Unpacked Folder (Recommended)
1. Open Google Chrome and go to `chrome://extensions` in the address bar.
2. Toggle on **Developer mode** in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select this folder:
   `c:\Users\taluk\OneDrive\Desktop\PROJECTS\Custom-New-Tab\chrome-theme`
5. Chrome will instantly apply the theme, turning your tabs and omnibox matte black!

### Method 2: Drag and Drop ZIP
1. Open `chrome://extensions` with **Developer mode** enabled.
2. Drag and drop `matte-black-theme.zip` directly onto the Chrome extensions window.
3. Click **Add theme** when prompted.

---

## To Revert or Change
- Go to Chrome **Settings** -> **Appearance** -> **Theme** -> Click **Reset to default**.
